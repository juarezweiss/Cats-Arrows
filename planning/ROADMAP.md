# Roadmap

## M0 - Repository and architecture foundation
- Codex governance/subagents/skill.
- Unity project baseline.
- Domain contracts and tests.
- CI validation skeleton.

## M1 - Deterministic Easy vertical slice
- Puzzle definition and validation.
- Easy candidate generator.
- Human-style solver + uniqueness verifier.
- Portrait board UI.
- Tap and drag marking.
- Clear/New Game/Menu/Hint shell.
- Immediate victory + completed-board state.
- iOS/Android device smoke test.

## M2 - Difficulty system
- Medium/Hard generation.
- Solver-derived difficulty metrics.
- Tutorial/onboarding.
- Accessibility settings.
- Save/resume.

## M3 - Product instrumentation
- Analytics provider selection.
- Crash reporting.
- Retention/behavior baseline.
- Internal/beta distribution pipeline.

## M4 - Monetization experiments
- Privacy/store review.
- Remove-ads/supporter IAP or cosmetics.
- Optional rewarded hint experiment only after instrumentation.

## M5 - Launch/growth
- Store listing/ASO.
- Creative test library.
- Small paid acquisition experiments with explicit stop rules.
