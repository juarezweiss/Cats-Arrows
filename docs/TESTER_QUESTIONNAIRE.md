# Cats & Arrows — First iOS friend trial (#21)

GitHub collection tracker: [Issue #22](https://github.com/juarezweiss/Paws/issues/22).
Use one response comment per tester/session and maintain its linked triage ledger.

Draft for owner review. This does not authorize invitations, purchases or app
distribution. Evaluate the accepted Easy game and explore visual direction;
no gameplay/art changes are prescribed by this questionnaire.

## Run the session

Allow 15–20 minutes to play, then roughly 5–10 minutes for answers and references.
Ask for private answers before discussing them as a group. Say: “We’re testing the
app, not your puzzle skills. Specific problems and things you would change are
more useful than being polite.” Let the first few minutes happen without coaching;
the built-in rules and Hint are available. If help is requested, give it and note
what was needed. Let them try 2–3 boards as time permits, without forcing completion.
Try Clear on a spare board so valuable progress is not unexpectedly erased.

Do not show the style references until after current-app questions. Use the same
questions for everyone, and allow Not tried / Not sure wherever appropriate.

## Questionnaire

1. In your own words, what is the goal, and what do the numbers and arrows tell you?
   Which rule, if any, remained unclear? (Listen especially for diagonal rays.)
2. Did any tap or drag do something you did not expect? Describe what you intended
   and what happened. (None is a valid answer.)
3. Were Hint, Clear, Menu and New Game easy to find and did they do what you expected?
   Choose Easy / Needed searching / Unexpected / Not tried for each; explain exceptions.
4. If you used Hint, did it immediately place a Cat or X as you expected, and
   could you continue playing without interruption? Yes / Partly / No / Didn't
   use it. Did you notice which cell changed? Describe anything unexpected.
5. How difficult were the boards for you? Very easy / Easy / About right / Hard /
   Very hard. Describe any difference between your first and later boards.
6. When stuck, what was the main reason? Couldn't find the next logical deduction /
   Didn't understand a rule / Couldn't interpret a symbol or clue / Input problem /
   Wasn't stuck / Other. An example is more useful than the rating alone.
7. Would you prefer the next boards to be Easier / Similar / Harder / More varied /
   Not sure? Why?
8. How easy was it to distinguish the following? Very difficult / Difficult / OK /
   Easy / Very easy, for each: Cat vs X; arrow direction including diagonals;
   fixed/hatched vs editable tiles; row/column numbers; button labels. If numbers
   were difficult, was it their meaning, size, contrast or association with a row/column?
9. Did you need to squint, move the phone closer, or carefully aim a tap? Where?
   Was the board comfortable to look at over the session?
10. Was it clear when a puzzle was finished? What did you want to do next?
11. Would you choose to open this game again on your own? Yes / Maybe / No.
    In what situation, or what would stop you?
12. What one change would most improve your experience?

## Visual comparison

Use real gameplay screenshots, not just icons or promotional banners. Show the
same number and size per reference: preferably one gameplay and one menu image
for each, to separate board art from menu density. Present all six with neutral
letters in a shuffled order. The table below is the facilitator key; do not label
options with evaluative words such as boring, premium, childish or overwhelming.
Links let the owner inspect examples without purchasing or installing them.

These style descriptions are our interpretation of the reference visuals, not
claims about their suitability or requests to copy their assets/mechanics.

13. Before seeing the references: how visually appealing is the current game?
    Very unappealing / Unappealing / Neutral / Appealing / Very appealing.
14. After seeing the references: which style do you personally like most, and
    which TWO fit Cats & Arrows best? Rank first/second. Current style / None / A
    combination are valid answers. Explain if personal taste and game fit differ.
15. What exactly would you borrow from those choices: colors, line shapes, cat
    illustrations, textures, depth, typography, menus or something else? What
    would you leave out?
16. Which reference looks easiest to read, and which feels most relaxing? They
    can be different choices. Would you prefer a quiet board with expressive cats,
    a more decorated environment, or something else? Ask the open question first.

## Observer notes and decisions

Record tester alias, device/OS, language/build, boards attempted/completed, hints
used, where they hesitated, unexpected inputs and whether they voluntarily started
another board. Note first-board completion time if practical; do not make it a
race. Record seed only if available; do not add a debug interface for this trial.

Distinguish logical difficulty from unclear rules or poor readability. Look for
repeated specific problems, then fix real blockers. With a few friends, counts and
quotes are more useful than population percentages. A popular reference is an
art-direction hypothesis, not a validated design for our board. A next small
comparison can render the same Cats & Arrows puzzle in the two preferred treatments
so mechanics, density and content stay constant. No new features or paid assets
are implied by preferring a colorful visual style.
