# Monetization Strategy

## Principle
Monetization must not destroy the calm/premium-feeling puzzle loop.

## Order of evaluation
1. Free core game with no monetization during product validation.
2. Optional supporter/remove-ads purchase.
3. Cosmetic board/cat themes.
4. Rewarded ad as an optional exchange for an enhanced hint or cosmetic benefit.
5. Very limited interstitial testing only if retention data supports it and frequency caps are strict.

## Prohibited baseline
- ad after every puzzle;
- forced ad before first meaningful play;
- fake close buttons;
- interrupting active deduction;
- designing puzzles to force Hint/ad consumption;
- production ad SDK activation before consent/privacy/store requirements are reviewed.

## Instrument before monetizing
Measure puzzle starts/completions, session depth, hint usage, abandon points, retention, and completion time before deciding ad placement.
